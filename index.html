How to Use the Attendance Scanner Terminal

Login: Use the branch username and password assigned by the Super Admin (e.g. username: cbcesilchar).

Face Mode: Position the student's face inside the green frame. Hold still for 1 second. The system will auto-detect, match, and record attendance.

QR Mode: Show the printed ID card QR code to the camera. Attendance is marked instantly.

Face+QR (Hybrid): First scan the QR card, then verify with face for maximum security.

New Person: If an unrecognized face is detected, a registration form will appear automatically. Fill in the details and save.

Arrival & Departure Logic

The first scan of the day marks Arrival. A second scan after at least 1 minute marks Departure. The session duration is calculated and stored. Scans within 1 minute of a recent scan are rejected to prevent duplicates.

Connecting Google Sheets as Cloud Database

1. Create a new Google Sheet. Click Extensions → Apps Script.

2. Delete all existing code and paste the provided Apps Script from the Cloud Sync tab.

3. Click Deploy → New Deployment → Web App. Set Execute as: Me. Access: Anyone.

4. Copy the generated Web App URL and paste it in the Cloud Sync configuration field.

5. Every attendance scan will now automatically sync to your Google Sheet in real time.

Installing the App (PWA)

Android: Open in Chrome → tap the menu (⋮) → "Add to Home Screen".

iPhone/iPad: Open in Safari → tap Share → "Add to Home Screen".

Windows/Mac: Open in Chrome or Edge → look for the install icon (⊕) in the address bar.

Once installed, the app opens in fullscreen standalone mode, perfect for kiosk terminals.

Deploying on GitHub Pages

1. Create a new GitHub repository and upload this index.html file.

2. Go to Settings → Pages. Set source branch to main, folder to /root.

3. GitHub will provide a public URL like https://yourusername.github.io/repo.

4. This URL can be bookmarked on all scanner devices.

Exporting & Printing Reports

Go to the Export Reports tab. Select Daily (today's records) or Monthly (current month). A professional A4 PDF will be generated with the institution header, attendance table, and signature section.

For spreadsheet use, download the CSV file and open in Microsoft Excel or Google Sheets.

Troubleshooting Common Issues

Camera not starting: Check browser camera permissions. Reload the page and allow access when prompted. HTTPS is required for camera access.

AI models not loading: Ensure stable internet connection on first launch. Models are ~6MB and cached after the first download.

Face not recognized: Ensure proper lighting. Face should be centered and close to the camera. Re-register if the original photo was taken in poor conditions.

Sheets not syncing: Verify the Apps Script URL is correct and the script is deployed as a Web App with access set to "Anyone".

Data lost after refresh: All data is stored in IndexedDB on the device. Do not clear browser data. Export CSV regularly for backup.

function doPost(e) {
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var data = JSON.parse(e.postData.contents);
    var sheetName = data.branch ? data.branch.replace('CBCE ','') : 'Attendance';
    var sheet = ss.getSheetByName(sheetName) || ss.insertSheet(sheetName);
    if (sheet.getLastRow() === 0) {
      var hdr = ["Date","Time","Action","Full Name","Type","ID / Roll","Course / Dept","Branch","Scan Mode","Duration","Confidence %","Status","Sync Time"];
      sheet.appendRow(hdr);
      var r = sheet.getRange("A1:M1");
      r.setFontWeight("bold").setBackground("#E8720C").setFontColor("white");
      sheet.setFrozenRows(1);
    }
    var now = new Date();
    var d = now.toLocaleDateString('en-GB');
    var t = now.toLocaleTimeString('en-US');
    sheet.appendRow([
      d, t, data.type, data.name, data.userType, data.idNumber,
      data.groupInfo, data.branch, data.mode,
      data.duration || "-", data.matchConfidence || "-",
      data.status || "Confirmed", new Date().toISOString()
    ]);
    // Also log to master sheet
    var master = ss.getSheetByName("Master Log") || ss.insertSheet("Master Log");
    if (master.getLastRow() === 0) {
      master.appendRow(["Date","Time","Action","Name","Type","ID","Course","Branch","Mode","Duration","Status"]);
      master.getRange("A1:K1").setFontWeight("bold").setBackground("#0D7A3E").setFontColor("white");
      master.setFrozenRows(1);
    }
    master.appendRow([d,t,data.type,data.name,data.userType,data.idNumber,data.groupInfo,data.branch,data.mode,data.duration||"-",data.status||"Confirmed"]);
    return ContentService.createTextOutput(JSON.stringify({status:"success",timestamp:now.getTime()}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status:"error",message:err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService.createTextOutput(JSON.stringify({status:"online",system:"CBCE Attendance v6"}))
    .setMimeType(ContentService.MimeType.JSON);
}
